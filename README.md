# 선원 유급휴가 계산기

승선일·하선일을 넣으면 회사 취업규칙·단체협약 기준으로 유급휴가 일수, 빨간날을 더한 휴가 기간, 조기승선 수당을 계산합니다.

| 무엇 | 어디 |
|---|---|
| 안드로이드 앱 (APK) | `apk/유급휴가계산기.apk` (1.1) — 휴대폰에서 이 파일을 내려받아 설치 |
| 자료 파일 (임금표·공휴일) | `data.json` — 앱이 인터넷이 될 때 받아 가는 파일 |
| 계산기 원본 (웹 화면) | `app/seafarer-leave.html` |
| 앱 소스·조립 스크립트 | `app/` (`build.sh`, `MainActivity.java`, `AndroidManifest.xml`) |

## 앱 설치 (휴대폰)

1. 휴대폰 브라우저로 이 저장소의 `apk/유급휴가계산기.apk`를 열고 **Download raw file**(내려받기) 버튼을 누릅니다.
2. 내려받은 파일을 열면 "출처를 알 수 없는 앱" 허용을 물어봅니다 → 이 브라우저(또는 내 파일)에서 설치 허용.
3. Play 프로텍트가 "알 수 없는 개발자" 경고를 띄우면 **무시하고 설치**(자세히 → 설치)를 누릅니다. 스토어에 올린 앱이 아니라서 나오는 안내입니다.
4. 설치 후 앱을 켜면 바다 위(오프라인)에서도 앱에 들어 있는 자료로 계산되고, 인터넷이 되면 `data.json`을 자동으로 받아 옵니다.

새 APK가 나오면 같은 서명키로 만든 것이라 **지우지 않고 그 위에 설치**하면 됩니다. 입력해 둔 값과 받아 둔 자료는 그대로 남습니다.

## 앱이 자료를 받아 가는 주소

`https://raw.githubusercontent.com/tanbaalbo/vacation_calculator/main/data.json`

앱 안의 "임금표·공휴일 자료" 칸에서 **인터넷에서 최신 자료 받기**를 눌러도 되고, 앱을 켤 때마다 인터넷이 되면 자동으로 확인합니다. GitHub에 올린 뒤 받아 가기까지 최대 5분쯤 걸릴 수 있습니다.

## data.json 안의 내용

| 항목 | 내용 |
|---|---|
| `dataVersion` | 자료를 고친 날짜 (고칠 때마다 바꿔 주기) |
| `wage` | 임금표 — 직책별 통상임금(`base`, 원), 호봉 1개당 단가(`step`, 원), 최대 호봉(`maxStep`) |
| `holidays` | 대한민국 관공서 공휴일 — 확정 발표된 해(`years`)와 날짜별 이름(`days`). 일요일은 계산기가 알아서 처리 |

## 매년 할 일

- **공휴일**: 다음 해 공휴일(한국천문연구원 월력요항, 보통 6월쯤)이 발표되면 `years`에 그 해를 넣고 `days`에 날짜를 추가
- **임금표**: 새 임금표가 나오면 `wage`의 금액·제목·시행일을 바꿈
- 고친 뒤 `dataVersion`을 고친 날짜로 바꿈

GitHub 화면에서 `data.json` → 연필 버튼(Edit)으로 직접 고치고 **Commit changes**를 눌러도 됩니다.
쉼표·따옴표가 하나라도 틀리면 앱이 자료를 못 읽고 기존 자료를 계속 쓰니(앱에 "오류가 있어 기존 자료를 그대로 씁니다"라고 나옴), 고친 뒤 꼭 앱에서 확인하세요.

인터넷 자료가 아직 안 올라왔을 때는 앱의 "임금표 직접 고치기"로 금액을 바꿔 쓸 수 있고, 나중에 새 판 자료를 받으면 직접 고친 값은 해제됩니다.

## APK 다시 만들기 (Claude 작업용)

Ubuntu에서 `apt install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23` 뒤:

```
app/build.sh <계산기 HTML> <서명키 .jks> <서명키 비밀번호>
```
